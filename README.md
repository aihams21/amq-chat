# عُمق — AMQ

واجهة محادثة عربية (RTL) تشتغل على اللابتوب والموبايل، بلا أي build step.
الواجهة ثابتة (HTML/CSS/JS) والاتصال بالموديل عبر OpenRouter.

## شو بتحتاج

1. حساب مجاني على [openrouter.ai](https://openrouter.ai) — بلا كرت.
2. مفتاح API بالشكل `sk-or-v1-...` من صفحة **Keys**.
3. حساب [Vercel](https://vercel.com) مجاني (بتقدر تسجّل بجيتهاب).

الموديلات المجانية (17 موديل) بتشتغل بلا رصيد. موديلات DeepSeek المدفوعة
بتحتاج رصيد ولو بسيط (V4.1-Flash-1017: ‎$0.038 دخل / ‎$0.50 خرج لكل مليون توكن).

## التشغيل المحلي

```bash
cd ~/deepseek-web
npx vercel dev          # http://localhost:3000
```

أو بلا Vercel CLI: افتح `index.html` مباشرة — بيشتغل بوضع «المفتاح المحلي»
(المفتاح بينحفظ بـ localStorage تبع المتصفح، وما بيطلع لأي سيرفر غير OpenRouter).

## النشر — 4 أوامر

```bash
npm i -g vercel     # مرة وحدة
cd ~/deepseek-web
vercel login        # يفتح المتصفح
vercel              # نشر تجريبي → بيعطيك رابط preview
vercel --prod       # النشر النهائي → https://<اسم-المشروع>.vercel.app
```

## خزّن المفتاح على السيرفر (الطريقة الآمنة)

بدل ما تحطّ المفتاح بالمتصفح، خلّيه Environment Variable على Vercel:

```bash
vercel env add OPENROUTER_API_KEY production
# الصق المفتاح، بعدين:
vercel --prod
```

أو من لوحة Vercel: **Project → Settings → Environment Variables**.
بعدها `/api/config` بيرجّع `{"mode":"server"}` والواجهة بتبعت الطلبات عبر
`/api/chat` — المفتاح ما بيوصل للمتصفح أبداً.

> إذا في مفتاح على السيرفر، الواجهة بتستعمله وتتجاهل المفتاح المحلي.
> إذا ما في، بترجع لوضع «المفتاح المحلي» وبتحفظه بـ localStorage على جهازك فقط.

## الملفات

| ملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة: الشريط الجانبي، المحادثة، صندوق الكتابة، نافذة الإعدادات |
| `styles.css` | نظام التصميم كامل (كحلي غامق + نحاسي)، وbreakpoint الجوال على 860px |
| `app.js` | الحالة، الموديلات، التخزين المحلي، ماركداون، بثّ SSE، مقياس السياق |
| `api/chat.js` | بروكسي متدفّق إلى OpenRouter (`maxDuration: 60`) |
| `api/config.js` | يقول للواجهة إذا في مفتاح على السيرفر |

## ملاحظات

- المفتاح **ما** بينحط بالـHTML ولا بالكود. أبداً.
- `amq.key` / `amq.thread` / `amq.model` / `amq.system` هي مفاتيح localStorage.
- زر **مسح الكل** بيحذف المحادثة والمفتاح من المتصفح.
- موديلات `:free` عندها حدود معدّل — إذا رجّع `429` استنى شوي أو بدّل موديل.
