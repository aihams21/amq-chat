# عُمق — AMQ·SEC

**الرابط الحيّ:** https://aihams21.github.io/amq-chat/

واجهة محادثة عربية (RTL) لعائلة **DeepSeek** فقط، عبر عدّة مزوّدين — كل مزوّد
بمفتاحه الخاص. مصمّمة كـ«ورشة أمن سيبراني»: شخصية أمنية، 119 مهارة جاهزة
(منها 91 منقولة من مكتبة OpenCode)، 13 حزمة إضافات مع بحث ويب وجلب صفحات
حقيقيين، وتحكّم حقيقي بجهد التفكير. بلا build step: HTML/CSS/JS فقط.

> على GitHub Pages ما في سيرفر، فالواجهة تشتغل بوضع **«المفتاح المحلي»**:
> كل مفتاح بينحفظ بـ`localStorage` تبع متصفّحك، وما بينبعث إلا للمزوّد صاحبه.

## جهد التفكير — low / high / max

| المزوّد | ما يحدث فعلياً |
|---|---|
| OpenRouter | يُرسَل `reasoning: { effort }`، وعند `max` يُضاف `max_tokens: 32000` |
| البقية | يُتجاهل الخيار، وتظهر ملاحظة «هذا المزوّد لا يدعم التحكم بالجهد» |

> توكنات التفكير تُحسب من `max_tokens`. لو رجع رد فارغ مع تفكير طويل،
> الواجهة تقول لك صراحةً: «الموديل صرف كل max_tokens على التفكير».

## المهارات (119)

**119 مهارة** = 28 مهارة أمنية/هندسية مكتوبة يدوياً + **91 مهارة منقولة حرفياً من
مكتبتك في OpenCode** (`~/.config/opencode/skills` → `data/skills-oc.js`): تصميم،
وثائق (docx/pptx/xlsx/pdf)، نشر، تداول، تسويق (Instagram)، كود، ذكاء اصطناعي،
بيانات، تخطيط. كل مهارة OpenCode تحمل وصفها الأصلي الكامل + محاورها + إجراءاتها.

نافذة **المهارات**: بحث + تصنيف (أمن / كود / تشغيل / تخطيط / تصميم / وثائق / بيانات /
نشر / تداول / تسويق / ذكاء اصطناعي)، بحد أقصى **12 مفعّلة** في نفس الوقت.
المهارة تُحقن كنصّ في رسالة النظام، لا كأداة تنفيذ.

استيراد مهارة خاصة: الصق ملف `SKILL.md` (اسم + جسم ≥ 20 حرفاً) → تُضاف للمجموعة
«مخصص» وتُحفظ محلياً. زر المسح يحذف المهارات المخصصة فقط.

## الإضافات (13 حزمة)

حزم تعليمات جاهزة (مراجعة كود، استجابة حوادث، تحليل شبكات، تقارير، بحث عميق،
هندسة عكسية، ميزانية سياق، 21st.dev، …).

**أداتان حقيقيتان تعملان من المتصفح بلا مفتاح:**

1. `websearch` — بعد تفعيلها يظهر زر **بحث ويب**. تكتب استعلاماً فيُجلب:
   - نتائج DuckDuckGo كاملة عبر `https://r.jina.ai/https://html.duckduckgo.com/html/?q=…`
   - احتياطياً ملخصات ويكيبيديا عبر `wikipedia.org/w/api.php` (CORS مفتوح)
   وتُدرج في المحرّر. **وأيضاً** النموذج نفسه يستطيع طلب بحث أثناء الإجابة بكتابة
   `[[SEARCH: استعلام]]`، فيُنفَّذ البحث تلقائياً (حتى جولتين) وتُحقن النتائج
   كسياق أدوات ثم يكمل الإجابة عليها.
2. `webfetch` — بعد تفعيلها يظهر زر **جلب رابط**، يجلب نصّ أي صفحة عبر
   `https://r.jina.ai/<url>` ويُدرجه في المحرّر.

الباقي تعليمات، لا تنفيذ أوامر (المتصفح لا يشغّل MCP حقيقياً — MCP يحتاج خادماً
على جهازك؛ هنا نُقلت **تعليمات** تلك الأدوات كحزم، مع أداتي البحث/الجلب الحقيقيتين).

## شخصية الأمن السيبراني

مفعّلة افتراضياً (شارة `SEC` في الشريط العلوي). الإطار: «مشغّل أمن مخوّل»
(مختبرك، أجهزتك، CTF، دراستك) → يقلّل الرفض الخاطئ ويجيب خطوات عملية.
الحدود الأربعة تبقى: لا ضرر على طرف ثالث بلا إذن، لا برمجيات خبيثة جاهزة للنشر،
لا احتيال/أسلحة/إساءة، ولا استهداف أنظمة الغير. عند الغموض يسأل سؤال تحديد نطاق
بدل رفض أعمى.

> **بصراحة:** هذا يقلّل الرفض غير المبرّر، لكنه **لا يزيل** طبقة الأمان عند
> المزوّد نفسه — بعض الطلبات قد تُرفض من OpenRouter/DeepSeek مهما كتبنا هنا.

## التشغيل المحلي

```bash
cd ~/deepseek-web
python3 -m http.server 4173     # http://127.0.0.1:4173
# أو مع بروكسي السيرفر الاختياري:
npx vercel dev                  # http://localhost:3000
```

## النشر

الموقع منشور على **GitHub Pages** من فرع `master` (مجلد الجذر). أي `git push`
يحدّث الرابط الحيّ خلال دقيقة.

البروكسي الاختياري على Vercel (للمزوّدين المحجوبين CORS أو لإخفاء المفتاح):

```bash
vercel env add OPENROUTER_API_KEY production
vercel --prod
```

`/api/config` يرجّع `hasServerKey`، و`/api/chat` يمرّر البثّ إلى OpenRouter.

## ملاحظات

- المفتاح **ما** بينحط بالـHTML ولا بالكود. أبداً.
- مفاتيح التخزين: `amq.v2.provider|model|effort|thread|keys|customModels|skills|customSkills|plugins|persona|system`.
- `amq.key` القديم يُرحَّل تلقائياً إلى `amq.v2.keys.openrouter`.
- زر **مسح الكل** (بالإعدادات) يحذف المحادثة والمفاتيح من المتصفح.
- موديلات `:free` عندها حدود معدّل — إذا رجع `429` استنى أو بدّل مزوّداً.
